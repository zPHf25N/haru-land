# HARU LAND (하루랜드)

> 나의 하루를 기록하면, 나만의 마을이 자랍니다.

공부·운동·휴식·사교 등 현실의 일상 활동을 기록하면 도서관·체육관·공원·카페가 생성되고 성장하는 웹 게임입니다. 기록의 결과를 마을의 변화로 보여 주어 꾸준한 기록과 균형 잡힌 일상을 돕는 개인 학술제 프로젝트입니다.

## 현재 상태

기획 및 저장소 초기 설정 단계입니다. 아래 게임 기능은 모두 **개발 예정**이며, 아직 실행 가능한 앱이나 배포된 서비스는 없습니다.

## 핵심 기능 (예정)

| 일상 활동 | 연결 건물 | 예정 동작 |
| --- | --- | --- |
| 공부 | 도서관 | 기록에 따라 생성 및 성장 |
| 운동 | 체육관 | 기록에 따라 생성 및 성장 |
| 휴식 | 공원 | 기록에 따라 생성 및 성장 |
| 사교 | 카페 | 기록에 따라 생성 및 성장 |

- 활동 유형, 날짜, 내용, 시간 등을 입력하는 활동 기록 (예정)
- 활동별 경험치와 건물 생성·레벨업 규칙 (예정, 수치 미정)
- 건물과 성장 진행도를 보여 주는 마을 화면 (예정)
- 활동 및 마을 상태 저장, 날짜별 기록 조회 (예정)

## MVP 범위 (예정)

1. 네 가지 활동 유형으로 기록을 남긴다.
2. 기록에 따라 해당 건물의 경험치와 성장 상태를 갱신한다.
3. 마을 화면에서 변화와 건물 레벨을 확인한다.
4. 새로 접속해도 저장한 기록과 마을 상태를 불러온다.
5. 날짜별 지난 기록을 조회한다.

완료 기준은 활동 입력 → 저장 → 건물 성장 → 재접속 후 상태 복원까지 시연하는 것입니다. 첫 버전은 규칙 기반 성장을 계획합니다. AI 일기 분석, 친구 방문, 캐릭터, 자유 배치, 감정별 분위기 및 고급 애니메이션은 MVP 이후 검토할 확장 기능이며 구현되지 않았습니다.

## 학술제 소개

HARU LAND는 일상 기록과 게임의 성장 보상을 연결하는 개인 제작 프로젝트입니다. 학술제에서는 활동을 기록한 뒤 마을 건물이 생성·성장하고, 기록과 상태가 저장되는 흐름을 시연할 예정입니다. 기획 의도, 성장 규칙, 구현 과정 및 한계를 소개하는 자료와 시연 영상을 준비할 예정이며 제출 목표일은 12월 18일입니다.
